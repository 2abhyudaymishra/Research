# DSA SDE1 Tracker

Topic-ordered LeetCode sheet for product-company **SDE1** prep (~1450 → 1750–1800+).

## Files

| File | Use |
|---|---|
| [`dsa-sde1-tracker.xlsx`](dsa-sde1-tracker.xlsx) | Excel tracker (recommended) — filters, dropdowns, topic sheets, clickable links |
| [`dsa-sde1-tracker.csv`](dsa-sde1-tracker.csv) | Same data; opens in Google Sheets / Numbers / Excel |

**Total: 215 problems** across 14 topics.

## How to use

1. Open the `.xlsx` (or import the `.csv` into Google Sheets).
2. Solve in topic order (see Overview sheet).
3. Update **Status**: `Todo` → `Doing` → `Done` (or `Revisit`).
4. Fill **Date Done**, **Attempts**, **Time (min)**, **Revisit** (`Y`/`N`), **Notes**.
5. Weekly: filter `Revisit = Y` and redo those problems.

## Suggested order

```text
Arrays & Hashing → Two Pointers → Sliding Window → Binary Search
→ Stack → Linked List → Trees → Heap → Graphs
→ Backtracking → DP → Greedy → Tries & Design → Bit & Math
```

## Columns

`Status | Topic | Order | Problem | Difficulty | LeetCode URL | Companies | Pattern | Date Done | Attempts | Time (min) | Revisit | Notes`

## Notes

- Company tags are **commonly reported** interview appearances; they change. Focus on patterns.
- Some problems (e.g. Meeting Rooms II, Alien Dictionary, Walls and Gates) may require LeetCode Premium.
- Contests 1–2×/week + same-day upsolve matter as much as finishing this list.
